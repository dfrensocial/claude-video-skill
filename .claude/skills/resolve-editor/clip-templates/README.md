# Clip templates (specs)

Each template = a spec the agent builds with Text+/HyperFrames/ffmpeg. Fill from the brief; never invent copy.

| id | purpose | length | elements |
|---|---|---|---|
| hook-card | opening text/graphic over first frame | 1.5-3 s | 1-2 line headline, accent keyword, brand bg or live footage under |
| stat-card | big number/claim reveal | 1.5-2.5 s | number count-up or pop, label, source line if a claim |
| offer-card | price/discount | 2-3 s | old price strike, new price pop, code |
| cta-end-card | closing | 2-3 s | logo, CTA text, handle/URL, brand colour |
| lower-third | name/title | 2.5 s | name, role, accent bar slide |
| transition-wipe | between sections | 0.4-0.6 s | brand-colour wipe on black for Screen/Add |

Added from the reference analysis (specs; look and numbers in `presets/`, technique IDs in references/reference-analysis.md):

| id | purpose | length | elements |
|---|---|---|---|
| info-card | one claim per card on brand yellow (T4) | 2-4.5 s | small-caps header, 2-line headline with red key phrase, one visual component |
| ring-percent | "91% / 99% chance..." style stat (T4/T7) | 2-3 s | ring draws 0->N over 0.6 s, number inside, caption below with accent words; only with a number from the brief |
| compare-card | original vs copy / before vs after (T4) | 3-4 s | two rounded cards, "VS" chip, bars fill ease-out; labels from the brief, no invented scores |
| collapse-grid | several brands/charts all trending down or up (T4) | 3-4 s | 2x3 mini line-charts with % change, closing chip "The exact same story." (copy from brief only) |
| pillar-stack | "3 pillars" / "stand alone" metaphor (T4) | 2.5-4 s | pillars rise with stagger, one hero pillar scales up |
| speed-callout | sped-up source clip (T6) | >= 3 s | speed-lines plate, rounded card, "2X SPEED" label, progress bar + timer |
| count-up | amount reveal (T7) | 1.5-2.5 s | label small above, number counts up ease-out, suffix "/-" |
| phone-card | b-roll in a floating rounded card (T5) | 1.5-3 s | 9:16 card on black or blurred A-roll, shadow, scale-pop |
| collage-label | torn-paper keyword (T10) | 0.8-1.5 s | yellow label, serif bold text, jitter 10 fps, optional newspaper plate |
| social-proof | like/comment/follow beat | 1-2 s | clip from `IG Animations` (alpha/screen), SFX pop |

Numbers and claims on any card must come from the brief/script verbatim. If the brief has none, make a text-only card or skip it, never invent a statistic.

Size = timeline resolution; fps = timeline fps; safe zones per platforms.md. Save finished good ones as presets.
