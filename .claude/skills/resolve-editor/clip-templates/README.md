# Clip templates (specs)

Each template = a spec the agent builds with Text+/HyperFrames/ffmpeg. Fill from the brief; never invent copy.

| id | purpose | length | elements |
|---|---|---|---|
| hook-card | opening text/graphic over first frame | 1.5-3 s | 1-2 line headline, accent keyword, brand bg or live footage under |
| stat-card | big number/claim reveal | 1.5-2.5 s | number count-up or pop, label, source line if a claim |
| offer-card | price/discount | 2-3 s | old price strike, new price pop, code |
| cta-end-card | closing | 2-3 s | logo, CTA text, handle/URL, brand colour |
| lower-third | name/title | 2.5 s | name, role, accent bar slide |
| transition-wipe | between sections | 0.4-0.6 s | brand-colour wipe on black for Screen/Add |

Size = timeline resolution; fps = timeline fps; safe zones per platforms.md. Save finished good ones as presets.
